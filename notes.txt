AirGradient -> senzorvzduchu.cz map (5th data source)

SOURCE
- Endpoint (no token, no registration):
  https://api.airgradient.com/public/api/v1/world/locations/measures/current
- Returns a JSON array with the latest reading for every public sensor worldwide (a few MB)
- No country/bbox filter in the API, so filter server-side
- Current values only. No history for sensors we don't own (that needs an org token)
- Licence CC BY-SA 4.0: map must show "Data: AirGradient (CC BY-SA 4.0)"

FIELDS (verified 2026-10-16)
- locationId (stable ID; NOT the loc= number in airgradient.com map URLs)
- locationName, latitude, longitude, timestamp (ISO UTC, e.g. 2026-10-16T07:57:26.000Z)
- pm02 = PM2.5 (raw). Likely also pm01, pm10, atmp, rhum, rco2 - check one record
- Check whether a corrected PM2.5 field exists (pm02_corrected?); prefer it over raw if so
- Some sensors have pm02 empty/null (e.g. 81353 Raškova, Řeporyje) -> skip or show grey

IMPLEMENTATION (mirror the PurpleAir integration)
- PHP proxy on Active24, same pattern as PurpleAir: curl with gzip (CURLOPT_ENCODING ''),
  file cache, TTL ~3 min, filter + normalise before caching (cache only the CZ subset)
- Lock file so cache expiry doesn't trigger parallel fetches; atomic write (tmp + rename)
- On fetch failure serve the stale cache, flagged stale
- Online = timestamp < 30 min old; older -> grey/offline marker
- Output the same normalised shape the map already uses for PurpleAir (id prefix "ag-")
- Own marker style/legend entry + attribution line
- Popup: name, PM2.5 (+PM10/T/RH/CO2 if present), age of reading, link to airgradient.com/map
